# Data attribution

This project uses Sentinel-2 Level-2A imagery. Contains modified Copernicus Sentinel data (2021-2026), processed by the authors.

* Source of the imagery: Copernicus Sentinel-2 mission (European Union / ESA), accessed through the Microsoft Planetary Computer STAC API (`sentinel-2-l2a`).
* Map background in the dashboard: (c) OpenStreetMap contributors.
* No satellite imagery is included in this repository; it is downloaded by `backend/scripts/fetch_sentinel2.py`.
* Results are research outputs and have not been validated against ground truth. See `docs/KNOWN_LIMITATIONS.md`.
